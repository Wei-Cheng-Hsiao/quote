# 展群室內設計 — 報價單系統（POC）

給父親（蕭樹德）使用的 iOS Safari 友善報價單系統。

## 特色

- **零安裝**：單一 HTML 檔，瀏覽器打開即用
- **零部署**：不需要 server，資料存在瀏覽器本地（localStorage）
- **iOS 友善**：手機/平板/桌機自適應介面
- **A4 標準版型**：左側清單編輯、右側即時預覽、瀏覽器列印成 PDF
- **品項庫**：預填 10 筆常用木作品項，可自由增刪改
- **客戶資料自動累積**：開單時順手存，下次搜尋姓名一鍵帶入
- **歷史報價**：可編輯、複製改版、刪除
- **匯出/匯入 JSON**：方便備份或換裝置

## 使用方式

### 桌機 / 父親自己用
直接雙擊 `index.html` 用瀏覽器打開即可。建議用 Chrome 或 Edge（Safari 也行）。

### 手機測試（同 Wi-Fi）
1. 在桌機跑簡易 server：
   ```bash
   cd C:\Users\qazz8\Documents\my-agent\100_Todo\projects\zhanqun-quote
   python -m http.server 8000
   ```
2. 查桌機區網 IP（`ipconfig` → IPv4），假設是 `192.168.1.10`
3. 手機 Safari 打開 `http://192.168.1.10:8000`

### iPhone 加到主畫面（變 App 體驗）
Safari 開啟頁面 → 分享 → 「加到主畫面」→ 之後從主畫面點開就像 App。

## 資料儲存位置

- 全部存在瀏覽器 `localStorage`（每個瀏覽器/裝置獨立）
- 三個 key：`zq_items` / `zq_customers` / `zq_quotes`
- **注意**：清除瀏覽器資料會遺失，定期用「匯出資料 JSON」備份

## 操作流程

1. **首頁** → 點「新開報價單」
2. **開單頁**：
   - 填客戶資訊（輸入姓名會搜尋舊客戶）
   - 在「加入品項」搜尋框找品項，點一下加入右側報價單
   - 可手動調整每筆的數量、單價（材料/費工另計直接改）
   - 找不到的品項點「建立新品項」或「加一筆空白項目」
   - 視需要勾選稅金、填折扣/訂金
3. **儲存** → 自動歸檔到歷史
4. **列印 / PDF** → 瀏覽器列印對話框 → 「儲存為 PDF」或實體列印

## 列印小技巧

- 列印時請選 **A4**、**直向**、邊界**最小**
- 印出來只會有報價單本體，介面按鈕不會印出來
- iPhone Safari：點分享 → 列印 → 縮放預覽可長按「儲存為 PDF」
